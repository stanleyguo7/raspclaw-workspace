# 北京近期活动信息源

最后整理：2026-09-11。

## 第一层：官方与场馆（作为事实核验来源）

| 来源 | 适合发现 | 使用方式 |
|---|---|---|
| [北京市文化和旅游局 / 北京旅游网](https://www.visitbeijing.com.cn/) | 节庆、展览、文旅路线、区域活动 | 优先查看活动专题和近期推荐；与主办方页面交叉核验。 |
| [首都之窗·北京要闻/各区热点](https://www.beijing.gov.cn/) | 全市和各区文化、消费、节庆活动 | 用于确认政府/区级主办的活动信息。 |
| [北京朝阳](https://www.beijing.gov.cn/ywdt/gqrd/) 及“醉美CHAO阳”官方账号 | 朝阳公园、亮马河、CBD、798 等朝阳区域活动 | 朝阳相关活动优先关注；活动当日以官方公告为准。 |
| 国家大剧院、北京展览馆、首都博物馆、UCCA、今日美术馆等场馆官网/官方号 | 演出、展览、讲座 | 针对已感兴趣项目复核时间、入场与预约。 |

## 第二层：票务与日程聚合（用于发现与购票核验）

| 来源 | 覆盖特点 | 核验提醒 |
|---|---|---|
| [大麦](https://www.damai.cn/) | 演唱会、演出、展览、节庆 | 确认场次、实名要求、入场规则、退改。 |
| [猫眼演出](https://www.maoyan.com/) | 演出、展览与本地票务 | 与主办方/场馆确认活动未改期。 |
| [秀动](https://www.showstart.com/) | Livehouse、独立音乐、音乐节 | 适合发现小型演出；确认地点和开场时间。 |
| [北京本地宝](https://bj.bendibao.com/) | 周末活动、展览、市集、区域指南 | 是高效聚合入口，不替代官方公告。 |
| [豆瓣同城·北京](https://beijing.douban.com/events/) | 小型讲座、放映、社群活动 | 适合发现小众活动；主办信息要二次验证。 |

## 第三层：社交平台（只作线索与现场体验）

| 平台/账号方向 | 价值 | 使用边界 |
|---|---|---|
| 小红书：北京周末、展览、亲子、望京、亮马河、朝阳公园等关键词 | 现场图、排队、拍照点、实际时长 | 只看近 30 天和带定位/票根内容；不将帖子作为活动必然举行的证据。 |
| 抖音：主办方、场馆、区域文旅官方号 | 临期节目单、直播、临时公告 | 以认证账号或主办方链接为准。 |
| 微信公众号/视频号：北京文旅、北京朝阳、场馆官方号 | 官方推文与预约入口 | 优先关注活动页中的日期和入场要求。 |

## 搜索模板

- `北京 本周末 展览 演出 市集`
- `朝阳 本周末 活动 亮马河 朝阳公园`
- `望京 本周末 活动`
- `顺义 后沙峪 周末 亲子 活动`
- `北京 + [活动名称] + 官方 / 主办方 / 预约`

## 输出格式

每条推送写清：**活动名｜日期与时段｜地点｜类型｜适合谁｜票务/预约｜信息来源｜临期核验提醒**。没有明确日期、地点或可靠来源的线索不推送。
