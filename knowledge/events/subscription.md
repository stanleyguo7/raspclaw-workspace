# 北京活动定期推送

## 当前规则

- 频率：每周四 11:00（Asia/Shanghai）。
- 执行：本机 `crontab` 调用 `scripts/weekly-beijing-events.sh`；脚本由 Codex CLI 生成摘要，以 `lark-cli` 创建飞书文档并通过机器人私信发送链接。
- 范围：未来 7–14 天的北京活动。
- 优先区域：朝阳、望京、顺义/后沙峪；同时保留少量值得专程去的全城活动。
- 类别：展览、演出、音乐节、市集、美食节、体育赛事、亲子活动。
- 每次推送：3–6 项；只收录已核验时间地点的项目，并附可访问的来源链接。
- 如活动临近、票务紧张、免费预约或有明显取消/改期风险，会在提示中标出。
- 运行前提：本机 Codex CLI 必须保持已登录；未登录时脚本只写日志、不创建文档或发送消息。

## 后续可调整

- 推送频率、时间与范围。
- 是否偏重亲子、音乐、艺术展、户外、体育、美食或免费活动。
- 是否加入工作日晚间活动、周边自驾活动或特定预算筛选。
