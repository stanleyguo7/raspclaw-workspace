## 同步约定

1. 先更新仓库中的源稿，再同步/更新飞书文档，并将最新提交写回本表。
2. 飞书端若发生实质编辑，先回读并合并到本地源稿，避免单向覆盖。
3. 餐厅营业状态、价格、预约规则和旅行交通等时效信息不作为长期事实；具体使用前重新核验。
4. 每次新增飞书知识文档时，向此表添加本地路径、飞书链接和对应 Git 提交。
