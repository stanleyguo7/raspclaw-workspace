# UI 规范（Workspace 文档站）

## 核心原则

1. **可读性优先**
   - 文字不重叠、不截断、不挤压。
   - 行高、字号、间距在手机端优先保证可读。

2. **简洁优先**
   - 不增加多余说明性文案。
   - 页面只保留当前任务必要信息。

3. **信息分级明确**
   - 重点信息：更大、更醒目、更靠前。
   - 次要信息：弱化颜色/字号或省略。

4. **移动端优先（Mobile First）**
   - 小屏先设计，再扩展到桌面端。
   - 导航允许换行，不允许内容重叠。

## 文案规则

- 标题：短、直接、可扫描。
- 描述：一句话内说明用途；可省则省。
- 禁止堆砌“解释性废话”。

## 布局规则

- 手机端默认单列。
- 卡片间距统一，避免视觉噪音。
- 目录层级清晰，但不做过度装饰。

## 交互规则

- 关键入口一屏可见。
- 链接文本清晰（看文字即可判断要去哪里）。
- 页面异常时优先显示可执行动作（刷新、返回入口）。

## 验收清单（每次改版必查）

- [ ] 手机端无文字重叠
- [ ] 标题与正文层级清晰
- [ ] 无多余说明文案
- [ ] 重点信息突出，次要信息弱化
- [ ] 首屏可快速定位主要入口
