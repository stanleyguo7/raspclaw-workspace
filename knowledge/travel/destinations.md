# 目的地候选清单（第一版）

> 这是用于筛选的起点，不是已确定的行程。最佳季节会受天气、节假日和个人偏好影响。

## 国内

| 目的地 | 适合主题 | 建议时长 | 适合季节 / 提醒 |
| --- | --- | --- | --- |
| 北京 | 历史、博物馆、城市漫步 | 4–5 天 | 春秋体感通常更舒适；热门场馆应提前预约。 |
| 西安 | 古都、历史遗址、美食 | 3–4 天 | 春秋优先；可与陕西周边自然景观组合。 |
| 成都 | 川菜、城市休闲、熊猫、周边山水 | 3–5 天 | 全年可选；雨季和节假日需预留交通弹性。 |
| 杭州 | 西湖、江南、人文与轻松度假 | 2–4 天 | 春秋适合慢游；可延伸至苏州或上海。 |
| 三亚 | 海滨、度假、水上活动 | 4–6 天 | 避开台风或强降雨时段；水上项目和海况以当地官方公告为准。 |
| 云南（大理 / 丽江 / 香格里拉） | 自然、古城、慢旅行 | 6–9 天 | 海拔与昼夜温差较大；跨城移动需预留休整日。 |
| 重庆 | 山城夜景、火锅、城市摄影 | 3–4 天 | 夏季炎热潮湿；适合与成都串联。 |
| 新疆（伊犁 / 喀纳斯等） | 公路、草原、雪山、摄影 | 7–12 天 | 目的地跨度大，季节性强；建议按路线和自驾能力单独规划。 |

## 国外

| 目的地 | 适合主题 | 建议时长 | 适合季节 / 提醒 |
| --- | --- | --- | --- |
| 日本（东京 + 京都 / 大阪） | 城市、美食、文化、购物 | 6–9 天 | 春赏花、秋赏叶需求高；城市间铁路衔接方便，票券与预约应按出发日期确认。 |
| 日本（北海道） | 自然、温泉、雪景 / 夏季避暑 | 5–8 天 | 冬季偏滑雪和雪景，夏季偏花田与避暑；需按季节选线路。 |
| 新加坡 | 城市、亲子、美食、短途海外 | 3–5 天 | 全年炎热多雨；公共交通便利，适合首次自由行。 |
| 泰国（清迈） | 慢旅行、文化、咖啡、美食、山地 | 4–6 天 | 关注雨季、空气状况及节庆日期；可将古城和周边自然路线结合。 |
| 意大利（罗马 + 佛罗伦萨） | 历史、艺术、建筑、美食 | 6–9 天 | 春秋通常适合步行游览；热门博物馆与景点建议预订。 |
| 新西兰南岛 | 自驾、徒步、湖山、摄影 | 7–12 天 | 与北半球季节相反；道路、天气和徒步线路须出发前复核。 |
| 葡萄牙（里斯本 + 波尔图） | 城市、人文、美食、海岸 | 5–7 天 | 春秋适合城市漫步；注意坡路和行李移动成本。 |
| 加拿大落基山脉 | 国家公园、湖泊、徒步、公路 | 7–10 天 | 夏秋较适合公路与徒步；部分设施和道路有季节性。 |

## 下一轮筛选问题

1. 更偏好自然风景、城市人文、美食、海岛度假、亲子，还是摄影？
2. 可接受的单程飞行时长和换乘次数？
3. 预算区间、旅行天数，以及是否偏好舒适慢游或高密度打卡？
4. 同行人、饮食限制、体力与住宿偏好？
