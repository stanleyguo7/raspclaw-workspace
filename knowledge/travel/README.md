# 旅行知识库

用于沉淀目的地研究、行程素材和旅行偏好，并在每次具体规划前复核时效信息。

## 文件

- `destinations.md`：国内与国外目的地候选清单。
- `traveler-profile.md`：仅记录用户明确表达的旅行偏好与约束。
- `sources.md`：优先使用的官方信息入口。

## 维护原则

1. 目的地记录包含适合的旅行类型、建议停留时长和季节性提示，不把动态价格、航班、签证或营业时间当作长期事实。
2. 做具体行程时，先确认出发日期、出发地、同行人、预算、节奏与证件要求，再查询最新交通、住宿和官方公告。
3. 偏好必须基于用户明确表达的内容；未知项保留为空，不从单次请求推断。
4. 实质更新按仓库约定 commit 并 push。
