# 旅行知识库

## 使用方式

这份知识库用于沉淀目的地研究、行程素材与旅行偏好。具体出行前，需按日期复核签证/入境、天气、交通、景点预约、住宿与安全公告。

## 国内目的地候选

| 目的地 | 适合主题 | 建议时长 | 提醒 |
| --- | --- | --- | --- |
| 北京 | 历史、博物馆、城市漫步 | 4–5 天 | 热门场馆建议提前预约。 |
| 西安 | 古都、历史遗址、美食 | 3–4 天 | 春秋优先，可延伸陕西周边。 |
| 成都 | 川菜、城市休闲、熊猫、山水 | 3–5 天 | 雨季和节假日预留交通弹性。 |
| 杭州 | 西湖、江南、人文慢游 | 2–4 天 | 可与苏州或上海组合。 |
| 三亚 | 海滨、度假、水上活动 | 4–6 天 | 海况与项目以当地公告为准。 |
| 云南（大理 / 丽江 / 香格里拉） | 自然、古城、慢旅行 | 6–9 天 | 注意海拔、昼夜温差与跨城移动。 |
| 重庆 | 山城夜景、火锅、城市摄影 | 3–4 天 | 夏季炎热潮湿，可与成都串联。 |
| 新疆（伊犁 / 喀纳斯等） | 公路、草原、雪山、摄影 | 7–12 天 | 季节性强，建议按路线单独规划。 |

## 国外目的地候选

| 目的地 | 适合主题 | 建议时长 | 提醒 |
| --- | --- | --- | --- |
| 日本（东京 + 京都 / 大阪） | 城市、美食、文化、购物 | 6–9 天 | 樱花和红叶季需求高，交通与预约按日期复核。 |

| 泰国（清迈） | 慢旅行、文化、咖啡、美食、山地 | 4–6 天 | 关注雨季、空气状况与节庆日期。 |
| 意大利（罗马 + 佛罗伦萨） | 历史、艺术、建筑、美食 | 6–9 天 | 热门博物馆与景点建议预订。 |
| 新西兰南岛 | 自驾、徒步、湖山、摄影 | 7–12 天 | 与北半球季节相反；道路和天气须复核。 |
| 葡萄牙（里斯本 + 波尔图） | 城市、人文、美食、海岸 | 5–7 天 | 注意坡路与行李移动成本。 |
| 加拿大落基山脉 | 国家公园、湖泊、徒步、公路 | 7–10 天 | 道路和设施有季节性。 |

## 旅行偏好档案

当前暂无稳定偏好记录。后续仅记录明确表达的信息，例如：

- 旅行节奏：慢游 / 均衡 / 高密度
- 偏好主题：自然、城市、人文历史、美食、海岛、购物、亲子、摄影
- 同行人、预算与住宿等级
- 可接受的飞行时长、换乘次数与签证便利度
- 饮食、体力、健康或无障碍需求
