# 美食餐厅知识库

用于沉淀北京餐厅候选清单、就餐场景与个人口味偏好。当前优先覆盖工作地望京、家庭地后沙峪/龙湾，以及偶尔值得专程前往的全城餐厅。

## 文件

- `beijing-restaurants.md`：按区域和场景整理的候选餐厅。
- `dining-profile.md`：仅记录用户明确表达过的口味、预算和就餐约束。
- `feishu-sync.md`：同步到飞书文档的可读版本。

## 维护原则

1. 小红书、点评类内容只用于发现线索；门店是否仍营业、地址、菜单、价格和预约规则必须在出发前以门店官方渠道、地图或近期评论复核。
2. 推荐理由侧重风味、场景和特色，不把单篇探店感受写成客观保证。
3. 将“已较新资料核验”和“待核验线索”分开；后者不能当作确定推荐。
4. 只有用户明确表达的偏好才写入个人档案。
